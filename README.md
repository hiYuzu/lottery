# 多人同步抽奖系统

面向年会与现场活动的实时抽奖系统，支持主持开奖、多端同步、投屏展示及活动管理。

## 安装依赖

运行环境为 Node.js 24。在项目根目录执行。

```powershell
npm ci
```

## 启动

```powershell
$env:ADMIN_PASSWORD = '请替换为管理员密码'
node server.js
```

打开[抽奖页](http://localhost:3000/)、[管理页](http://localhost:3000/admin.html)或[投屏页](http://localhost:3000/?display=1)。其他设备将 `localhost` 替换为服务电脑的局域网 IP。

密码设置在当前 PowerShell 会话中生效，新开终端需重新设置。登录管理页后可进入主持台开奖。

## 自定义配置

### 活动与奖项

在管理页新建或切换活动，设置活动名称、正式或彩排模式，以及奖项名称、总名额、每轮人数和阳光普照类型。奖项修改后点击「保存」。

### 抽奖名单

在管理页的「名单」中按行填写 `姓名,地区,编号`，点击「预览」后「导入」。编号可省略，同名人员需使用不同编号。各活动名单独立，新建活动需单独导入。

`data/list.json` 用于初次初始化及旧数据迁移，格式如下。已有活动的名单通过管理页维护。

```json
{
  "name": [{ "id": "001", "name": "张三", "dept": "BJ" }]
}
```

地区为 `CN` 的人员仅参加阳光普照奖。所有奖项均排除本活动已中奖人员。

### 背景音乐与音效

替换 `public/music/bg.mp3` 设置循环背景音乐，替换 `public/music/win.mp3` 设置中奖音效。刷新页面后点击「音乐」启用。

### 年份

修改 `public/common.js` 中的 `EVENT_YEAR`，默认值为 `2027`。刷新页面后生效，统一用于抽奖页、管理页、登录页和中奖海报。

### 服务参数

启动前在同一 PowerShell 窗口按 `$env:变量名 = '值'` 设置，修改后重启服务。

| 变量             | 默认值             | 用途                                               |
| ---------------- | ------------------ | -------------------------------------------------- |
| `ADMIN_PASSWORD` | 必填               | 管理员密码                                         |
| `PORT`           | `3000`             | 服务端口                                           |
| `HOST`           | `0.0.0.0`          | 监听地址                                           |
| `DATA_DIR`       | 项目目录           | 活动状态与签名密钥的保存目录                       |
| `PUBLIC_URL`     | 自动识别局域网地址 | 二维码访问根地址，如 `https://lottery.example.com` |
